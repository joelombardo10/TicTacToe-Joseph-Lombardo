# TicTacToe - Joseph Lombardo

## Run locally
1. Install Node.js.
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000

## Deploy on Render
- Create a GitHub repository and upload the project files.
- In Render, create a new **Web Service** and connect that repository.
- Build command: `npm install`
- Start command: `npm start`
- Deploy the service, then replace the placeholder above with your Render URL.
